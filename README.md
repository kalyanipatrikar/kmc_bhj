# kmc_bhj
Monte Carlo based multiscale model to obtain device properties of bulk heterojunction organic photovoltaic based on molecular and interface properties computed by first principles.
Procedure is described in 'From Molecules to Devices: A Multiscale Approach to Evaluating Organic Photovoltaics' (https://pubs.acs.org/doi/10.1021/acs.jctc.4c01029)
File maincode.py solves for an example case of OPV with donor PM6 and non-fullerene acceptor AQx2. 
Different molecular configurations of AQx2-PM6 molecular interface are generated by xTB based method and distributed randomly throughout simulation grid.
File AQ contains the rates of charge separation and recombination at interface AQx-PM6 interface configurations, and rate of electron hopping for AQx-2. 
File PM6 contains the charge transfer integral for different interface configurations.
maincode.py results in short circuit current and open circuit voltage for the PM6-AQx OPV device.
